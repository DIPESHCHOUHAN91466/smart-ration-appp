# api — API contracts

**What:** machine-readable descriptions of the two HTTP APIs, **generated from the code** — never edit
them by hand.

| File | API | Generated by | Kept current by |
|---|---|---|---|
| `openapi/python-api.openapi.json` | Python API (:8000): auth, public help, chatbot, health | `backend/SmartRation.Python/scripts/export_openapi.py` (no server needed) | a test fails when it drifts from the code (`tests/test_api_contract.py`) |
| `openapi/csharp-api.swagger.json` | C# API (:5188): bookings, QR, OTP, inventory, collections, AI panels | the same script with `--csharp http://localhost:5188` (needs the C# API running in Development) | refresh after changing C# endpoints |

**Why:** a reviewable record of every endpoint, request and response shape — for code review
(`git diff` shows API changes), client generation, and API testing tools (import into Postman,
Insomnia or VS Code REST clients).

```
cd backend\SmartRation.Python
.venv\Scripts\python scripts\export_openapi.py                              # Python contract
.venv\Scripts\python scripts\export_openapi.py --csharp http://localhost:5188  # + C# contract
```
Human-readable overview: [../docs/api/API.md](../docs/api/API.md). Live docs: http://127.0.0.1:8000/docs and
http://localhost:5188/swagger.
